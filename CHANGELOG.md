# Changelog

All material changes to the GNOME Prompt Field Manual are recorded here. Dates use UTC. A release entry describes the committed artifact; it does not imply that every prompt pattern behaves identically across model families or versions.

## [1.0.0-rc.1] - 2026-08-06

### Added

- Deterministic, network-free structural validation for `index.html`.
- Source-SHA-256-bound JSON and Markdown validation evidence.
- Unit tests for success and failure paths.
- Read-only GitHub Actions quality gate with non-persistent checkout credentials.
- Explicit release-quality, correction, and model/version-sensitivity requirements.
- Release-candidate version record.

### Status

This is an auditable release baseline, not the final stable release. Source-grounded examples and counterexamples, technical-claim review, accessibility review, and browser-matrix validation remain open.

## [0.1.0] - 2026-05-24

### Added

- Initial public single-page field manual and repository README.
