07 / Independent verification

To verify a capsule, run the Python v3 replay tool from the checked-out GNOME repository:

python3 tools/reactor_campaign_replay.py verify capsule.json

It recalculates scores using Evidence Spine v2, validates intervention bindings, checks claim-to-trial links and detects modified evidence.

Still not proved: source authenticity, reviewer identity, whether a claimed model run occurred, or independent replication.
