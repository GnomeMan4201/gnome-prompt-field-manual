## Testing method and limits

The temporary server supported a dedicated **POST capture route**. The temporary test copy of the browser app posted the exact export Blob to that route while also using its ordinary export code path. Python validated the captured bytes directly, not a hand-built equivalent fixture.

For reimport, a second temporary QA-only control fetched the captured file and passed it as a browser `File` to the **unchanged application import function**. This exercised the application's real import logic against exact exported bytes, but **did not test selecting the downloaded file through the operating system's native file picker**. Do not claim that native file-picking is covered.

The temporarily edited HTML, test capture route, test buttons and `QA-TEST-ONLY` decision are **not committed**. They are test harness fixtures, not editorial approvals or production changes.

## Not executed

- **390 px viewport/browser mobile emulation**: Browser automation could not resize the viewport. Responsive behavior is not empirically verified.
- **Tab/Enter/Space keyboard-only interaction**: The automation could inspect native buttons, but could not send keyboard events. Keyboard functionality was not empirically exercised.
- Full accessibility testing (screen reader, contrast, WCAG audit), cross-browser compatibility, native file-picker import, and review of every source location.

These are outstanding usability acceptance checks and should not be silently counted as passes.

## Status and interpretation

The structural and security-critical review data flow is tested successfully: **source hash -> source span -> user-entered review record -> browser JSON Blob -> Python validator -> browser File reimport**, with observed negative cases rejecting tampered source identifiers and tampered HTML.

This does **not** certify editorial truth or entry bodies. The production queue still contains **629 pending human decisions**; **0/91 independently verified canonical bodies**.

No production app code or canonical source document was modified by this acceptance report.
