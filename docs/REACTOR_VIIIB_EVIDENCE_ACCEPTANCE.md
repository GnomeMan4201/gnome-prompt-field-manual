- Explicit `SOURCE: UNVERIFIED CANDIDATES` and reviewer-reference disclaimers.

The browser's native downloaded file bytes were not exposed by that automation environment. A **temporary test-only capture route** was therefore added to an isolated copy (not GitHub) that posted the **same Blob** generated by the ordinary browser export handler.

Exact captured file:

- **5,058 bytes**.
