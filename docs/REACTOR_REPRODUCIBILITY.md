# GNOME // EVIDENCE REACTOR — Reproducibility Levels
1. **Computational Replay**: Deterministic recomputation of hashes, paired trial attributions (`BASELINE_FAILURE`, `VARIANT_INDUCED_FAILURE`, `SHARED_FAILURE`, `VARIANT_IMPROVEMENT`, `UNATTRIBUTABLE`), and capsule integrity without contacting a model provider.
2. **Execution Reproduction**: Rerunning the same prompt/input/model configuration against a live provider.
3. **Independent Replication**: A separate researcher conducting a new experiment with independent observations.
