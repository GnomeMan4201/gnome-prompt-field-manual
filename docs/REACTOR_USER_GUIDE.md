1. **Mode 01 (Method Selector)**: Select from the 91-entry baseline or load a clearly labeled `SYNTHETIC DEMONSTRATION` onboarding case.
2. **Mode 02 (Prompt Microscope)**: Inspect Source vs. Control vs. Variant with LCS line diff and content-hash variant IDs.
3. **Mode 03 (Experiment Designer)**: Define hypothesis, dataset, rubric, and model/provider parameters (seed stays `null` if unsupported).
4. **Mode 04 (Execution Chamber)**: Import offline observation JSON (Path A) or opt into a local Ollama-compatible endpoint (Path B).
5. **Mode 05 (Comparative Analysis & Counterfactuals)**: Inspect baseline attribution, comparability classification, and file Adversarial Challenges.
6. **Mode 06 (Capsule & Replay)**: Export portable `gnome.reactor.capsule.v1` JSON, verify SHA-256 checksums, and run offline computational replay.
